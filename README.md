# TCXPowerScaler

TCXPowerScaler is a command-line utility that adjusts power values in Garmin TCX activity files. It is useful when you need to uniformly scale recorded power data after calibration changes, or equipment differences.

# Features

* Batch-processes all .tcx files in a folder.
* Preserves the original file before making changes.
* Before a file is modified, the original file is copied to: filename.tcx.original
* Supports command-line automation.
* Supports interactive entry of the scaling factor when not provided on the command line.

# Usage

## Interactive Mode

Run the executable without arguments:  TCXPowerScaler.exe

The application will:

* Use the current directory as the working folder.
* Prompt for a scaling factor.
* Process all .tcx files in that folder.

## CLI Mode

**TCXPowerScaler.exe scale:1.05**

Adjusts all TCX files in the current folder, adding 5% to each power reading.

**TCXPowerScaler.exe scale:0.97 folder:C:\Activities**

Adjusts all TCX files in C:\Activities, subtracting 3% from each power reading.

# Why This Exists

The project originated from a simple real-world request.

A cyclist needed to adjust the power values in a large collection of ride files. The initial plan involved exporting data and modifying it manually in Excel. While possible, this process would have required significant effort and introduced opportunities for mistakes.

From a software perspective, the task was straightforward:

* Read a TCX file
* Locate power values
* Apply a percentage-based adjustment
* Produce a corrected output file

Because the transformation is deterministic, software can perform it quickly and correctly every time.

TCXPowerScaler was built to automate that workflow with the smallest practical solution.

# Design Philosophy

This project intentionally favors simplicity.

Rather than building a web application, hosted service, or graphical user interface, TCXPowerScaler is distributed as a standalone console application.

Reasons for this approach include:

* No server infrastructure
* No hosting costs
* No user accounts
* No external dependencies
* No data uploaded to third-party services
* Easy to run when needed
* Easy to delete when finished

The application performs one task and does not attempt to be a broader training analysis platform.

# Features
* Scale all power values in a TCX file by a configurable percentage
* Preserve the original ride structure and metadata
* Fast processing for large files
* No network connection required
* Simple command-line operation

# Compatibility

The tool works with standard TCX files generated by cycling computers, training applications, and other platforms that export TCX activity data.

A later update improved compatibility with files produced by a user-reported recording application that emitted leading whitespace before the XML document. Although technically invalid XML, these files were encountered in the real world and are now handled automatically.

# Project Goals

It is deliberately focused on doing one thing well.
